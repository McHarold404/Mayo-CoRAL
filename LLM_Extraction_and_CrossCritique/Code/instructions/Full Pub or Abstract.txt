Column Name: Full Pub or Abstract
Definition: Indicates whether the study results were fully published or only an abstract is available.

Detailed Extraction Instructions:
- Step 1: Search the document for explicit statements indicating whether the study is a "full publication," "full paper," "complete manuscript," or if it is an "abstract," "conference abstract," or "poster presentation."
- Step 2: If the document is an abstract, confirm that it is explicitly labeled as such (e.g., "Abstract" at the beginning of the document).
- Step 3: If the document is a full publication, look for indicators such as a journal name, volume, issue, and page numbers.
- Step 4: If the document is neither a full publication nor an abstract, or if it is unclear, mark the column as "not present."
- Step 5: If the document is a full publication, extract the text "Full Pub". If the document is an abstract, extract the text "Abstract".

Key Reminders:
- Do not assume a document is a full publication just because it is lengthy. Look for explicit indicators.
- Be careful not to confuse a full publication with a pre-print or a manuscript submitted for publication.
- If the document is a full publication, it should have a journal name, volume, issue, and page numbers.
