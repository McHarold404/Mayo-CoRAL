Dynamic Query Generation Prompt Template

Task:
Given a set of column attributes and their definitions from a clinical study table, generate a BM42+ query that retrieves document chunks containing all the necessary information to extract the values for these columns. The query should be robust enough to capture both descriptive/statistical context and numerical values from tables, charts, or graphs.

Instructions:

Extract Key Phrases and Synonyms:

For each column, analyze its definition to identify the critical terms and phrases. For example, if a definition mentions “hazard ratio,” also consider including synonyms or related terms that encapsulate the same concept (e.g., “risk ratio,” “relative risk” if contextually appropriate).
List all related synonyms or alternate phrases for each key term to ensure that the query captures variations in the document text.
Structure the Query:

Combine the key phrases and their synonyms using logical operators:
AND: to require that specific terms (or any of their synonyms) appear together.
OR: to allow for variations between different columns or for alternative synonyms.
Use parentheses to group related phrases and synonyms.
Example: For “hazard ratio” and its synonym “risk ratio,” you might structure it as: ("hazard ratio" OR "risk ratio")
Optimize for Numerical Values and Tables:

If the column attributes are numerical (e.g., rates, percentages, statistical values):
Include an instruction in your query to specifically target chunks that contain tables.
Assume that tables are stored in markdown format. Therefore, include markers or terms such as “|” (pipe character) or "markdown table" to help retrieve these sections.
Example Addition:
Append a condition like AND ("markdown" OR "|" OR "table") to your query when numerical values are expected.
Combine the Query Elements:

Ensure that your final query string integrates:
The extracted key phrases.
Their synonyms.
Logical operators and grouping for clarity.
Additional conditions for numerical values (e.g., table markers) if applicable.
Example Construction:
For the column "OS Rate (%) | Synchronous | Control" with the definition:
“Hazard ratio with confidence intervals of overall survival (OS) of all comparisons in all participants with synchronous metastases in the control arm.”
Key Phrases & Synonyms:
(“hazard ratio” OR “risk ratio”)
“confidence intervals”
“overall survival”
(“synchronous metastases”)
(“control arm”)
Numerical/Statistical Optimization (if applicable):
Append conditions to retrieve markdown tables: AND ("markdown" OR "|" OR "table")

Final Query Example:

(("hazard ratio" OR "risk ratio") AND "confidence intervals" AND "overall survival") AND ("synchronous metastases" AND "control arm") AND ("markdown" OR "|" OR "table")
Output:

Your final output should be a single, cohesive BM42+ query string that combines all necessary key phrases, synonyms, and conditions to ensure that the document chunks retrieved contain the required descriptive and numerical information.
