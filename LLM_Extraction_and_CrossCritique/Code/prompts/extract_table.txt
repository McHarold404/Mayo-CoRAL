*Task:* Extract structured tabular data or interpret visual figures/charts from a scientific page image (typically from a medical or clinical study).  
Format results as a Markdown table if a *table* is present. Otherwise, extract and interpret the *figure* or *chart* content and produce an informative caption.

---

*Instructions:*

1. *Identify Content Type:*
   - Determine whether the image primarily contains:
     - A structured *table*, or
     - A visual *figure/chart* (e.g., bar plot, Kaplan-Meier curve, scatter plot).
   - If both are present, prioritize the *table*, unless the figure dominates.
   - If neither is present, return the phrase:  
     ➤ "No table or figure found"  
     and stop.

---

2. *If a Table is Present — Follow These Steps:*

   a. *Extract Headers:*
      - Identify column and row headers.
      - If column headers are multi-level, combine them using " - " (e.g., "Treatment Group - Mean Age").
      - Include units in headers or data cells if applicable.

   b. *Extract Data:*
      - Preserve original formatting: decimals, percentages, symbols, confidence intervals, etc.
      - Include statistical formatting (e.g., mean ± SD, n (%), median [IQR], p-values).

   c. *Footnotes:*
      - If visible in the image, extract any footnotes, symbol explanations (*, †, ‡), or glossary terms.

   d. *Format Table in Markdown:*
      - Use standard Markdown syntax (| and -).
      - Do not simulate merged cells.

   e. *Generate Caption:*
      - Include table number and title (verbatim if shown).
      - Describe the table contents, structure (columns, rows), data types, and any visible footnotes or abbreviations.
      - Mention study context if inferable (e.g., "Participants with metastatic prostate cancer").

---

3. *If a Figure/Chart is Present — Follow These Steps:*

   a. *Extract and Describe the Figure:*
      - Identify the figure label and title (e.g., "Figure 3. Kaplan-Meier survival curves").
      - Describe the type of chart (e.g., line graph, KM curve, forest plot).

   b. *Interpret Elements:*
      - Summarize visible labels, axes, and group comparisons.
      - Mention any statistics shown (e.g., p-values, HRs).
      - Include any legible annotations or legends.

   c. *Generate Caption:*
      - Provide a description of what the figure shows (trends, group differences).
      - Mention chart type, axis labels, data comparisons.
      - Include study population or outcome if visible.

---

*Output Format:*

If a table is extracted:

##Markdown Table##

[Markdown table here]

##Caption##

[Enriched caption describing table content]



If a figure is extracted:

##Markdown Table##

No table found

##Caption##

[Interpretation of figure/chart, including title, type, axes, and visible insights]



*Important Notes:*
- Be accurate. Do not infer beyond what’s visible.
- Output must follow the format above with no extra commentary.
- Prioritize the table if both exist, unless the figure clearly dominates.
