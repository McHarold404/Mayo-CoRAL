NCT — ClinicalTrials.gov identifier for the trial.

PMID — PubMed identifier for the trial publication.

Authors — Listed authors of the publication.

Year — Publication year.

Original/Follow Up — Whether the report is the initial primary analysis or a subsequent follow-up.

Study name — Official/commonly used trial name or acronym.

Trial phase — Development stage (I/II/III/IV) defining objectives/scope.

Number of arms — Count of experimental plus control arms.

Original publication or Follow-up — Same as “Original/Follow Up,” for datasets that include both fields.

Cancer type — Disease/indication (include stage/setting when relevant).

Treatment regimen — Full prespecified therapy for experimental arm(s): drugs, doses, schedules, cycles, and any RT/surgery/ADT.

Name of ICI — Exact immune checkpoint inhibitor(s) used.

Class of ICI — Target pathway of the ICI (e.g., PD-1, PD-L1, CTLA-4, LAG-3, TIGIT).

Monotherapy/combination — Whether ICI is given alone or with other anticancer therapy.

Type of combination — If combination: partner class (e.g., ICI+chemo, +targeted, +hormone, +ICI, +RT, triplet/multimodal).

Control regimen — Assigned comparator treatment (e.g., placebo, BSC, SOC chemo X, ADT alone, physician’s choice).

Type of control — Control category: placebo-controlled, active-controlled, standard-of-care, best supportive care, or observation.

Total sample size — Total participants enrolled/randomized across all arms (analysis population).

Lines of treatment — Prior systemic therapy lines and/or the line under study (e.g., 1L, 2L+).

Clinical setting in relation to surgery — Neoadjuvant, Adjuvant, Perioperative, Maintenance, or Metastatic/Recurrent (unresectable).

Is PD-L1 positivity inclusion criteria — Yes/No; record cutoff and assay if applicable (e.g., CPS ≥10, TPS ≥50%).

Is any other biomarker used for inclusion — Yes/No; specify marker and cutoff (e.g., MSI-H/dMMR, TMB-high, EGFR/ALK, BRCA).

Primary endpoint — Main prespecified outcome (e.g., OS, PFS, pCR, EFS, RFS/DFS, ORR).

Primary multiple/composite/co-primary? — Indicates co-primary endpoints, composite endpoint, or multiple-primary families.

Secondary endpoint — Additional prespecified outcomes (e.g., DoR, TTR, CBR, QoL, safety, landmark survival).

Type of follow-up given — Reported follow-up metrics (median, range/IQR, landmark timepoints, data-cut date; KM censoring noted).

Follow-up duration for primary endpoint(s) in months — Median follow-up at primary analysis, split as:
	[Overall] — Entire study population.
	[Rx] — Experimental arm.
	[Control] — Control arm.
